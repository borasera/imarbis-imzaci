# imarbis İmzacı — kurulum paketleri

**Kurulum için:** https://imarbis.com.tr/imzaci/

imarbis İmzacı, e-imza kartıyla imarbis'te tarayıcıdan, belge indirmeden imza
atmayı sağlayan küçük bir masaüstü uygulamasıdır. Bilgisayarda yalnız
`127.0.0.1`'de çalışır; PIN'i kendi penceresinde sorar, PIN siteye gitmez.

Bu depo yalnız **kurulum paketlerini** taşır (`paketler` dalı):

| Dosya | Sistem |
|---|---|
| `imarbis-imzaci-macos.pkg` | macOS (Apple Silicon ve Intel) |
| `imarbis-imzaci-windows.exe` | Windows 10 / 11, 64 bit |
| `surum.json` | Yayınlanan sürüm |

Paketler imarbis'in CI'ında üretilir ve `paketler` dalı her sürümde baştan
yazılır; elle değiştirmeyin.
